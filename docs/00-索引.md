# 网页展台文档索引

> 最后更新：2026-08-01

## 项目简介

“网页展台”是一款 Windows 桌面软件，用于通过 SSH 管理阿里云 Ubuntu 服务器上的静态展示网站。用户选择已经制作好的网页文件夹，软件完成校验、压缩、上传、发布、更新、回收和恢复，并生成可直接分享的公网链接。

## 快速定位

- 修改客户端界面或上传流程：先读 `02`，涉及远程调用时同时读 `04`。
- 修改服务器文件布局或 Nginx：先读 `03` 和 `08`。
- 修改命令、字段、状态或错误码：先读 `04`，不得破坏兼容性。
- 修改总体技术栈、安全边界或数据流：先读 `01`，并同步更新本索引。
